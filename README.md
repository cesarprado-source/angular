# Angular
## Framework CSS
El framework seleccionado para los estilos es **Bootstrap**.

## Scripts útiles
- `npm install` – Instala todas las dependencias del proyecto.  
- `ng serve` – Inicia el servidor de desarrollo y habilita la aplicación en modo local.  
- `ng build` – Compila la aplicación y genera la versión lista para producción.  

## UI Template

Este proyecto utiliza un template gratuito de la página oficial de Bootstrap.

### Fuente
- **Nombre del template:** Dashboard  
- **URL:** [https://getbootstrap.com/docs/5.3/examples/dashboard/](https://getbootstrap.com/docs/5.3/examples/dashboard/)
